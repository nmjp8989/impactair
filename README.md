# ImpactAir

Static website for ImpactAir inflatable billboard rentals. Each page has its own HTML file. The stylesheet, JavaScript and WebP images are in `assets/`.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/ (root)** and save. The site uses relative links and requires no build step.

## Content

The provided design artwork supplies the images. Campaign examples are labeled as concepts. The quote form opens an email draft to `info@impactair.ca`. Visitors send the draft from their email app.
